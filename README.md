# UZKORLOVE - WEBSITE
Uzkorlove: A website for Korean make up products and cosmetics shopping
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Uzkorlove is a social web application designed for online shopping of Korean cosmetics and various make up products
<img width="640" height="412" alt="image" src="https://github.com/user-attachments/assets/12fc9f0f-4a7c-4945-980b-6cc9e65e3727" />

Users(customers) can create profiles, sign in and order Korean cosmetics through the screens and got their products been delivered right to Uzbekistan in front of their doors!!
This repository contains the full project code, organized with separate folders for frontend, backend, assets, and documentation.

<img width="640" height="412" alt="image" src="https://github.com/user-attachments/assets/bd9a64a7-04e0-4c80-af1b-e13d56524cb3" />

Tech stack: [React/HTML/CSS/JS, Node.js/Django, Database, etc.].
